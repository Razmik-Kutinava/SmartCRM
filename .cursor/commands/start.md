# /start — старт сессии / задачи (умный)

SmartCRM. Канон: `smartcrm-task-workflow.mdc` § «Старт сессии» + шапка-only ниже.

## Режим (выбери один)

### A) Узкий старт (по умолчанию)

Если в чате/todo уже есть задача, баг локализован, или продолжение той же фичи.

Сделай **только**:

1. `HANDOFF.md` — **шапка до первого `---`** (`Read` limit ~25–40), не всё тело
2. `SESSION_STATE.md` — то же (шапка + 1–3 свежие строки журнала)
3. `ISSUES.md` — только **открытые** 🔴/🟡 (не архив)
4. `todo.md` — если живая задача
5. `BACKLOG.md` — **не** читать целиком; Grep по пункту чеклиста только если нужен хвост
6. Таблица: `last_done` | `current_state` | `next_step` (по одной строке)
7. Должки ISSUES старше месяца — блок «подтверди закрытие или оставляем»
8. **ctx-trim:** если пт–вс и `ctx_trim` в HANDOFF старше 7 дней — одна строка «рекомендуется `/ctx-trim`» (не блокировать)

**Не читать без просьбы:** тело старых HANDOFF-карточек, весь CHANGELOG, `docs/archive/`, весь CHECKLIST_F4, PRD, `ZONE_NOTES` целиком (только раздел зоны задачи), CRITICAL_LEDGER (только на `/crit-audit` / hot-path review).

### B) Полный старт + PHASE 0

Только если **новый** заказ ещё не в `todo.md` § «Заказ (дословно)», или пользователь явно просит intake.

Тогда: PHASE 0 (цитата в todo + пункт чеклиста/спека) → краткая шапка ops → `Next: /spec` (или стоп до `go`/`ебашь` по SBR).
