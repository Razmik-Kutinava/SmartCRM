# scratch — одноразовые скрипты агента

Временные скрипты для отладки и разовых прогонов. **Не** pytest, **не** prod CLI.

- После шага: удалить или перенести в `backend/scripts/` с нормальным именем + README + тест
- Не коммитить секреты и дампы
- Артефакты вывода → `backend/data/` или `backend/data/artifacts/`

Канон: `.cursor/rules/workflow/smartcrm-repo-layout.mdc` §1.
