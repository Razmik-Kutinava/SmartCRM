# Email UI — референс Яндекс.Почты

Канон приёмки: [`F4_EMAIL_YANDEX_UI.md`](../operations/phase4/email/F4_EMAIL_YANDEX_UI.md).

## Что копируем с рабочего ящика

1. **Сайдбар** — тёплый градиент, заголовок «Почта», жёлтая кнопка «Написать», иконка обновления.
2. **Навигация** — Входящие (с числом), Главное, С вложениями; блок «Мои папки»; Отправленные / Удалённые / Спам / Черновики.
3. **Поиск** — скруглённое поле «Поиск», кнопка «Найти», ряд чипов-фильтров под строкой.

## Что остаётся SmartCRM-специфичным

- Панели «Массовая (сегмент)», «Касания», «Управление кампаниями» — внизу сайдбара.
- Анализ + черновик Маркетолога, апрув отправки, nurture — без изменения UX Яндекса в списке.

## Просмотр треда

- **Центр:** одно выбранное письмо — шапка (от кого, кому, дата), абзацы без цитат.
- **Справа:** «Письма на тему» — клик переключает письмо; ‹ Пред / След ›.
- **Цитаты:** обрезаются по `----------------` / `Кому:…Тема:`; полный текст — в «Показать с цитатами».
