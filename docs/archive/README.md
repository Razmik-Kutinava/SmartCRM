# Архив

Старые отчёты, тест-планы и устаревшие процессы. **Не** основной канон — для истории.

- [deprecated-process-2025-05.md](deprecated-process-2025-05.md) — устаревший процесс агента (май 2025)
- `ops/` — архив ops-журналов по месяцам (`YYYY-MM_{CHANGELOG,HANDOFF,SESSION_STATE}.md`); живые файлы в `docs/operations/session/` держат только текущий месяц
- `product/` — старые продуктовые доки (PRD_NOTES, PRD_DELTA и т.п.)

Актуальная документация: [../README.md](../README.md).  
Процесс разработки: [../operations/baselines/RULES_MATRIX.md](../operations/baselines/RULES_MATRIX.md).
