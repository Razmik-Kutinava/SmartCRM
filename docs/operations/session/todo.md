`onMount` вешает `page.subscribe(pullLead)` — подписка срабатывает **на любое** изменение URL, включая `?panel=`/`?tab=`. `pullLead` при том же лиде звал `sync()` + `syncDetailsDraftFromLead()` + `syncContactsDraftFromLead()` → черновик пересобирался из сохранённого лида, незаполненная третья форма пропадала, и следующий ввод шёл в предыдущую карточку.
