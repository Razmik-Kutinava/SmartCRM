## Найдено (диагностика 2026-08-01)

Цепочка бага (воспроизведена на лиде 244 через браузер + аудит):

1. Сохранение уходит корректно — PATCH со **всеми тремя** контактами, в БД 3 (проверено `GET /api/leads/244`).
2. `saveContactsFields` вызывает `fetchLeadById`, но **результат выбрасывает**, а `lead` берёт из `sync()` → кэш списка `smartcrm_leads_cache_v2`.
3. Кэш обновляется только после `await fetchLeads()` — на 3258 лидах это больше 10 секунд, всё это время `lead` старый (2 контакта).
4. `syncContactsDraftFromLead()` пересобирает форму из старого `lead` → **третий контакт исчезает и из формы**.
5. Пользователь правит второй контакт, жмёт «Сохранить» → PATCH уходит с 2 контактами → **третий стёрт в БД**. Аудит #130 это подтверждает: было 3, стало 2 с правкой второго.
