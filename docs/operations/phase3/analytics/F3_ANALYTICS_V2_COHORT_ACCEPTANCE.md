# Аналитика v2 — когортный анализ (acceptance)

**PRD_MAP:** «Когортный анализ»

## Было

- Сводка KPI и воронка по стадиям
- Конверсия по источнику
- Нет среза «месяц входа лида → конверсия»

## Стало

| Компонент | Изменение |
|-----------|-----------|
| `core/analytics_metrics.py` | `compute_cohorts()` — месяц входа, won/lost/active, conversionPct |
| `GET /api/leads/analytics/summary` | поле `cohorts` в ответе |
| CSV export | секция когорт |
| `/leads/analytics` | блок «Когорты по месяцу входа» |

## Критерии

- [x] Лиды группируются по `createdAt` (YYYY-MM)
- [x] Конверсия = выиграно / всего в когорте
- [x] UI + API + pytest

## Не в scope

- Когорты по неделе / кварталу (можно Ф4)
