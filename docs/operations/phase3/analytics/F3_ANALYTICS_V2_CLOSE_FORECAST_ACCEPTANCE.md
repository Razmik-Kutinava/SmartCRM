## Формула (v1)

- База по стадии (Новый 8% … Переговоры 58%)
- Смесь с баллом лида: `0.55 × стадия + 0.45 × score`
- Выигран = 100%, Проигран = 0%

## Критерии

- [x] Прогноз только для активных лидов (не won/lost)
- [x] Тиры high / medium / low
- [x] pytest unit + API
