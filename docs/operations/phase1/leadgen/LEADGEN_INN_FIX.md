# Leadgen — развод ИНН мок vs live (2026-06-10)

## Проблема

ИНН `7736207543` в ЕГРЮЛ = **ООО «Яндекс»**, в тестовых фикстурах был записан как вымышленный **«ТехноСофт»**. Checko работал корректно — расхождение только в тестовых данных.

## Решение

| ИНН | Назначение | Где |
|-----|------------|-----|
| `7707070010` | Фейковый «ТехноСофт» | Только pytest с замоканным Checko |
| `5040048921` | ООО «Хохланд Руссланд» | Live smoke, DevTools, UI placeholder |
| ~~`7736207543`~~ | Реальный Яндекс в ЕГРЮЛ | **Не использовать** в тестах/smoke |

Канон: `backend/leadgen/inn_constants.py` (re-export в `tests/fixtures/leadgen/`)

## Проверка

```bash
cd backend && python -m pytest tests/test_leadgen.py tests/api/test_leadgen_portrait_api.py -q
cd backend && python scripts/smoke_leadgen_portrait.py
```

UI: `/leadgen` → «По портрету» → ИНН `5040048921` → «Найти компании» → блок «Эталон для поиска» = Хохланд.
