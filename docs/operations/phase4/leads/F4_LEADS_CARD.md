## Финальный состав (сверху вниз)

1. **Компания** — название; адрес (город + адрес из Checko/паспорта read-only, если есть)  
2. **Контакты** — один тип сущности, несколько штук; «с кем говорим» + ручной ввод  
   Поля: должность, телефон, рабочий, email, соцсети, мессенджеры  
3. **Сайт** — домен (часто из почты) + индикатор живой / мёртвый  
4. **Отрасль · ОКВЭД · чем занимаются** — сайт + интернет + Checko; кнопка Исследование  
5. **Сотрудники**  
6. **Обороты с нами** — продали/купили + откуда цифра  
7. **Выводы агентов** — после запуска из плитки «Агенты»  
8. **Системные** — источник · ответственный · создан  

Сырые UF Битрикса — **хвост** (свёртка), не центр. Маппинг → нормальные поля (ИНН, домен, email лицензии, цены).

## Апрувы (логика)

| # | Что | Критерий «готово к апруву» |
|---|-----|----------------------------|
| **1** | Каркас порядка блоков | Секции в нужном порядке; UF в хвосте; Паспорт без правок; системные на месте |
| **2** | Контакты | ≥2 контакта сохраняются; выбор «с кем говорим»; ручной ввод; нужные поля |
| **3** | Сайт = домен + alive | Домен из email/UF; зелёный/красный статус |
| **4** | Отрасль / ОКВЭД / исследование | Поля на карточке; 🔍 / исследование через поисковики + Checko |
| **5** | Обороты + выводы агентов | Блок оборотов понятен; выводы агентов на карточке после «Агенты» |

Между апрувами — стоп, ждать «ок» / `go` на следующий.
