# Ф4 — Тендеры на карточке лида

**Дата:** 2026-08-15  
**Чеклист:** «Ф4 · Тендеры на лиде (плитка + поисковик)»

## Зачем

Лид = досье компании. Плитка **Тендеры** — прошлое и текущее по ИНН/имени, без отдельного похода на `/tenders`.

## Контракт

- `GET /api/leads/{id}/tenders` — кэш `checko.analyses.lead_tenders` (без сети).
- `POST /api/leads/{id}/tenders/search` — живой поиск:
  - Checko-контракты (уже на лиде, иначе live `/contracts` role=supplier)
  - DataNewton `governmentContractsStat` (заказчик)
  - TenderGuru: поиск по имени + планы по ИНН
  - Веб-поисковик SmartCRM: Brave / Serper / Tavily (`компания ИНН тендер`)
- **Без LLM.** `usage.llm_tokens = 0`. Поисковики тарифируются запросами/кредитами, не токенами Groq.

## UI

Шестая плитка хаба **Тендеры**. Кнопка «Искать». Сводка + текущие / прошлые / веб. Строка стоимости поиска.

## Не в этом шаге

Win rate подрядчика как точная цифра; Контур.Закупки; сохранение каждого тендера в `tender_saved`.
