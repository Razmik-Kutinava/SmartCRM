## Как должно быть (решения владельца)

### Скор
- Скор в шапке / приоритет — **автоматический**, не ручное поле «поставь 50».  
- **Сейчас в коде иначе:** `score` в БД — ручной; авто только `scoreAdvisory` (этап + сумма ₽ + галочки пути − просрочки) и **не пишет** в `score`.  
- Целевой смысл скора: готовность к продаже (этап/путь + полнота карточки; на поздних этапах — почти полная карточка).  
- Отрасль / паспорт / enrich — должны влиять (сейчас в advisory **не входят**).

### «Мой день»
- В очереди только лиды с **делом на сегодня** (или просрочка).  
- Среди них сверху — **ближе к деньгам** (этап + путь сделки).  
- Нет дела сегодня → не в «Мой день», даже при высоком скоре.  
- **Сейчас:** `dayRank` уже есть (этап+путь+задачи), но правило «только с делом сегодня» как жёсткий фильтр — уточнить/дожать относительно [`F4_DAY_PRIORITY.md`](F4_DAY_PRIORITY.md).

### Шапка карточки `/leads/[id]`
- **Убрать** дубль этапа из мета-строки (этап только кнопками воронки ниже).  
- **ИНН → отрасль** в шапке (ИНН остаётся в Клиент/Паспорт).  
- Нет отрасли → суфлёр: обогатить/исследовать и проставить (нужно для рассылок по продуктам).  
- **🔍 Исследовать** — мёртвая кнопка (нет `onclick`); либо привязать к `/search` по компании, либо убрать.  
- 📤/🅰/🅷 — выгрузка лида **из** SmartCRM в Битрикс/Amo/HubSpot (не импорт).

### Путь сделки
- Это **чеклист галочек** (не файлы PDF).  
- Часто в UI: «Все шаги пройдены» + **0/0** → `dealPath` пустой/не пришёл, не «всё закрыто». Разобрать и починить.

### Хаб
- 5 плиток ок: Клиент · Работа · Письма · Продукты · Агенты (уже в коде).  
- Клиент = Карточка|Паспорт; Работа = История|Задачи; Письма = переписка + рассылка.

### Рабочий пул / импорт (ещё не кодили)
