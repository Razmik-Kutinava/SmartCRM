## П.1 — Модалка «Новый лид» (дашборд + список)

**Было:** кнопка «+ Новый лид» на дашборде — ссылка на `/leads/list` без создания; на списке — `prompt()`.

**Стало:**
- Глобальная модалка `LeadCreateModal` (layout host)
- Дашборд → `openLeadCreateModal({ source: 'Дашборд' })`
- `/leads/list` → та же модалка, обновление списка после POST
- POST `/api/leads` → PostgreSQL, кэш `smartcrm_leads_cache_v2`
