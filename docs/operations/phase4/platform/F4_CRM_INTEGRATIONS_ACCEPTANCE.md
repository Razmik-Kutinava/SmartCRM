## MVP интеграций (обязательно)

Делаем **поэтапно**, приоритет OAuth/подключения: **Битрикс → Amo → HubSpot**.

### 1. Экран подключения

- [ ] **`/ops/integrations`**: карточки Битрикс24, AmoCRM, HubSpot (+ Telegram отдельно в платформе)
- [ ] Статусы: не подключено / подключено / ошибка / токен истёк + последняя проверка
- [ ] Кнопка «Проверить соединение» (ping API)

### 2. OAuth и credentials (топ-3)

- [ ] **Битрикс24 (№1):** входящий вебхук-URL в UI (или OAuth, если портал поддерживает); тест `crm.lead.list`
- [ ] **AmoCRM (№2):** OAuth или long-lived token + subdomain в UI
- [ ] **HubSpot (№3):** OAuth private app / PAT в UI

### 3. Security wrapper

- [ ] **Шифрование токенов at rest** (AES-256 или эквивалент), ключ из env/KMS — не plaintext в БД
- [ ] **Middleware исходящих вебхуков:** проверка подписи / `application_token` (расширить паттерн Битрикса)
- [ ] Валидация входа API-роутов интеграций (без инъекций в маппинг/CSV)

### 4. Импорт и выгрузка «в 1 клик»

- [ ] Импорт всех лидов из подключённой CRM с list (кнопки уже есть — привязать к UI credentials)
- [ ] **CSV:** шаблон колонок + подсказка «любая CRM → экспорт → импорт»
- [ ] Экспорт CSV со списка (уже есть — довести UX и ссылку из integrations)

### 5. Маппинг полей и стадий (ручной)

- [ ] Таблица в Ops: стадия SmartCRM ↔ стадия внешней CRM
- [ ] Базовый маппинг полей (company, contact, stage, source…) — без LLM на MVP
- [ ] Подсказки на `/leads/list` вместо голого 503 → «Настроить в Ops → Интеграции»

### 6. Живой синк (после MVP подключения)

- [ ] Битрикс: мастер исходящего вебхука + `BITRIX_OUTBOUND_TOKEN` в UI
- [ ] Расписание авто-импорта (интервал в UI)
- [ ] Исходящие webhooks Amo → наш endpoint (по `go`)

## Явно не в MVP интеграций

| Тема | Почему |
|------|--------|
| **AI-маппинг полей (LLM)** | После ручного маппинга и 2–3 живых клиентов → BACKLOG |
| **Kanban / табы / DnD** | Уже в Ф1 (`/leads/funnel`, карточка) — не дублировать |
| **Zoho / Salesforce / 1С** | Новый адаптер по запросу, после топ-3 |
| **Мультитенант credentials** | Ф5+ / SaaS |
