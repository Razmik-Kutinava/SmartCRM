## Что в Ф3 сделано, но «сыро» для обычного пользователя

| # | Сейчас | Боль |

| 6 | Битрикс исходящий вебхук | Нужен публичный URL (туннель) — в BACKLOG |

## План Ф4 — Платформа (чеклист)

### A. Интеграции без `.env` (главный UX-гэп)

- [ ] Страница **`/ops/integrations`** (или секция в Ops): Битрикс24, AmoCRM, HubSpot, Telegram
- [ ] **Сохранение credentials в БД** (шифрование at rest), не в git/env для prod-пользователя
- [ ] Статусы: `не подключено` / `подключено` / `ошибка` / `токен истёк` + последняя проверка
- [ ] **Битрикс24:** ввод `BITRIX24_WEBHOOK_URL` в UI, тест `crm.lead.list`, маскирование секрета
- [ ] **AmoCRM:** OAuth или long-lived token через форму + subdomain
- [ ] **HubSpot:** OAuth private app / PAT через форму
- [ ] **Telegram:** привязка чата (QR / `/start` + авто-`chat_id`), без ручного `getUpdates`
- [ ] Убрать требование «спроси админа про .env» с подсказок кнопок на `/leads/list`

### B. Синк CRM (глубже, чем кнопка)

- [ ] **Расписание:** авто-импорт Amo/HubSpot/Битрикс (интервал в UI, как `BITRIX_AUTO_SYNC_MINUTES`)
- [ ] **Двусторонний push:** опция «при сохранении лида → в CRM» (не только кнопка на карточке)
- [ ] **Маппинг стадий/источников** SmartCRM ↔ внешняя CRM (таблица в Ops, не только эвристика по имени)
- [ ] **Конфликты:** кто главный при расхождении полей (last-write / manual queue)
- [ ] **Битрикс исходящий вебхук:** мастер URL + `BITRIX_OUTBOUND_TOKEN`, подсказка туннеля для dev
- [ ] Bulk export: «выгрузить всех без `amo_lead_id` в Amo» и аналоги для HubSpot/Битрикс

### C. Telegram (хвост после MVP)

- [ ] Уведомления **тендеров** (дедлайн, вердикт участия)
- [ ] **Дайджест** lead hunt (раз в N часов, не каждый кандидат)
- [ ] Несколько chat_id / роли (оператор vs руководитель) — `TELEGRAM_ALLOWED_CHAT_IDS` в UI
- [ ] Голосовые команды через бота — **вне scope**, только если явный go

### D. Баллы P3 — закрыто в Ф3

- [x] SLA-протоколы + эскалация → [`F3_SLA_PROTOCOLS_ACCEPTANCE.md`](../../phase3/leads/F3_SLA_PROTOCOLS_ACCEPTANCE.md)

**Тюнинг Ф4 (остаток по баллам):** [`F4_SCORING_TUNING.md`](../leads/F4_SCORING_TUNING.md) — UI весов, breakdown, фильтры списка, связка с прогнозом.

### E. Качество и приёмка

- [ ] Smoke-скрипт или чеклист: живой Битрикс / Amo / HubSpot / Telegram (опционально в CI с secrets)
