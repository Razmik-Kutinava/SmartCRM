# OWNER_CHECKS — Фаза 4 (проверка владельцем)

> Чек-лист «действие → ожидание» после пакета агента.  
> Агент дописывает ≤12 пунктов на пакет в `/review`.  
> Всё совпало — напиши агенту **«ок»** (тогда `[x]` в `CHECKLIST_F4.md`).  
> Не совпало — номер пункта + что видно → агент чинит через новый шаг / `/sbr`.  
> Проверка **не блокирует** следующие задачи фазы.

## Как пользоваться

1. Пройти пункты на стенде (обычно `http://localhost` / ваш runbook).
2. «Не проверено агентом» — делает владелец (живая почта, Bitrix, ключи API).
3. После «ок» агент закрывает пункт чеклиста.

---

## Пакет: нечёткий поиск названия (2026-11-14)

1. F5 → `/leads/list` → в поиске `втф банг` при наличии лида «ВТБ Банк» → список не пустой, ВТБ в топе, бейдж «похоже».
2. Точный запрос `втб` / полное имя — без чужих «похожих» сверху exact.
3. Голос: «найди лид втф банг» → те же кандидаты; фраза «открой её» **не** открывает слабый fuzzy-матч молча (нужен явный выбор / точный поток open_lead).

**Не проверено агентом:** STT с реального микрофона (владелец).

## Пакет: open_lead overlay (2026-11-05)

1. F5 → «найди лид …» → «открой её» → модалка с карточкой, blur сзади.
2. Esc / × / клик вне — закрыть; «На весь экран» → `/leads/{id}`.

**Не проверено агентом:** нет.
