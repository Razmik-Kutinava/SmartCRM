**Откуда:** Ф3 закрыл базу (когорты, агенты по трейсам, воронка по источнику, прогноз Экономиста).

Связанные acceptance Ф3: `docs/operations/phase3/analytics/F3_ANALYTICS_V2_*.md`

## План Ф4 (чеклист)

### Прогноз закрытия

- [ ] Поле лида `expected_close_at` (дата) + UI в карточке
- [ ] Прогноз на **карточке лида**: %, ожидаемые ₽, tier (high/medium/low)
- [ ] Срез **«ожидаемое закрытие по кварталу/месяцу»** на `/leads/analytics`
- [ ] **Калибровка** `STAGE_CLOSE_BASE_PCT` по реальным won/lost из БД (скрипт + периодический пересчёт)
- [ ] **LLM-Экономист по запросу** на лид: уточнение прогноза + rationale, кэш в snapshot/JSON

### Эффективность агентов

- [ ] 👎/👍 **по агенту** в трейсе (или разметка «кто косячил»)
- [ ] Из `/ops/stats` → **needsAttention** → кнопка «A/B» / «Суфлёр» с предзаполненным агентом
- [ ] Авто-очередь Ops: агент ниже порога satisfaction → задача в queue (опционально, вкл. в настройках)

### Когорты и воронка (polish)

- [ ] Когорты по **неделе / кварталу** (переключатель на analytics)
- [ ] Экспорт PDF блока аналитики (если не взяли в «Платформа»)

## Критерии готовности Ф4 (acceptance)

- [ ] Открыл лид → видишь прогноз без перехода в analytics
- [ ] Задал дату закрытия → в analytics виден прогноз по кварталу
- [ ] После 20+ закрытых сделок базовые % стадий подтянуты из истории
- [ ] 👎 на трейсе можно привязать к агенту → stats отражает точнее
- [ ] Из stats «Улучшить» → improve с контекстом агента в 1 клик
