# SmartCRM — Roadmap

> План фаз верхнего уровня. Рабочие чеклисты живут в операционке: `docs/operations/phase{N}/CHECKLIST.md`.

## Фазы

| Фаза | Суть | Статус | Чеклист |
|------|------|--------|---------|
| **Ф1 — MVP** | Ядро: лиды (CRUD, Kanban, задачи), балльная воронка P1, голос по лидам, поиск/RAG базово, лидоген, тендеры baseline, аналитика базовая | ✅ закрыта (DoD 6/6, 2026-06-11) | [`Чеклист: Фаза 1 — MVP`](../operations/phase1/CHECKLIST.md) |
| **Ф2 — Автоматизация** | Voice Layer на все модули, Email-агент (черновик → апрув → отправка), поиск → RAG авто, версии промптов, оркестрация (Стратег fanout), баллы P2 | ✅ очереди 1–9 пройдены | [`Чеклист: Фаза 2 — Автоматизация`](../operations/phase2/CHECKLIST.md) |
| **Ф3 — Автономия** | Email-автономия (FAQ, рассылки, 20 касаний), vendor crawl → RAG, тендер-мониторинг 24/7, аналитика v2 (когорты, прогноз), SLA P3, экспорт | ✅ по блокам | [`Чеклист: Фаза 3 — Автономия`](../operations/phase3/CHECKLIST.md) |
| **Ф4 — Тюнинг и MVP** | Доводка до продаваемого MVP: интеграции CRM (Битрикс/Amo/HubSpot), email-тюнинг, «Мой день», A/B промптов, суфлёр Стратега, аналитика v2 тюнинг | 🔄 **текущая** | [`Чеклист: Фаза 4 — Тюнинг и MVP`](../operations/phase4/CHECKLIST.md) |

## Что дальше (после Ф4)

- Прод-инфра и безопасность перед деплоем (роли, аудит, secrets)
- Telegram-бот, внешние интеграции по мере продаж
- Контур.Закупки — после первой тендерной сделки (gate)
