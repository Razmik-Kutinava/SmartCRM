# PRD Notes — отрывки и уточнения

> **Зачем:** сюда вставляешь тексты «как есть сейчас», «как должно работать», навигация, слабые места, идеи по фазам.
> Агент читает этот файл, сверяет с [`PRD_MAP.md`](PRD_MAP.md) и [`PRD.md`](PRD.md), потом раскидывает по нужным докам (voice, modules, ARCHITECTURE) — **сам файл остаётся рабочим инбоксом**.

**Не канон.** Источник правды после разбора: `PRD_MAP` → `PRD` → `ARCHITECTURE` → `docs/modules/`, `docs/voice/`.

---

## Как вставлять

1. Копируй блок текста в нужный раздел ниже (или добавь новый подраздел).
2. В шапке блока укажи дату и модуль, если неочевидно.
3. Можно писать черновиком, списком, диаграммой — формат свободный.
4. После разбора агентом сюда можно оставить краткую ссылку «→ перенесено в …» или удалить дубль.

Шаблон блока:

```markdown
### [YYYY-MM-DD] Название темы

**Фаза:** 1 | 2 | 3 | не знаю
**Статус:** есть в коде | частично | только идея
**Слабое место / блокер:** (если есть)

(твой текст)
```
