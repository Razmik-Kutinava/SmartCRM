## Что строим (одна строка)

**Один человек голосом управляет 5 AI-агентами = полноценный отдел продаж.**

---

## Карта документа

```
PRD.md
│
├── 🎯 ИДЕЯ И ПРОБЛЕМА
│   └── Один оператор заменяет отдел продаж; голос — основной интерфейс
│
├── 🗺️  ROADMAP (3 фазы)
│   ├── Фаза 1 — MVP [в работе]
│   │   ├── Лиды — ✅ в основном готово
│   │   ├── Голос → лиды (Whisper→Hermes→CRUD)
│   │   ├── Тендеры — базово (парсеры + Serper)
│   │   └── Баллы P1 — scoreAdvisory, суммы ₽
│   │
│   ├── Фаза 2 — Автоматизация
│   │   ├── Voice Layer — голос во ВСЕХ разделах
│   │   ├── Email-агент — IMAP/SMTP, черновик, апрув
│   │   ├── Поиск → RAG (авто-чанки)
│   │   ├── Оркестрация (Стратег fanout)
│   │   └── Баллы P2 — комментарии, аудит, правила стадий
│   │
│   └── Фаза 3 — Автономия
│       ├── Голос: подтверждение + история
│       ├── Email: авто-ответы, цепочки 20 касаний
│       ├── Self-improvement: краулинг, A/B промптов
│       ├── Тендерный агент (платный API)
│       └── Telegram, внешние CRM, экспорт
│
├── ⚙️  МОДУЛИ (детали)
│   │
│   ├── 🎙️ Voice Layer
│   │   Whisper → Hermes (модуль+интент) → LangGraph → UI-реакция
│   │   UI-реакции: модалка / навигация / фильтр / апрув
│   │
│   ├── 📧 Email-агент
│   │   IMAP читает → агент анализирует → черновик → апрув → отправить
│   │
│   ├── 🧠 Self-improvement
│   │   Поиск/PDF/диалог → чанки → RAG агента → агент умнеет
│   │
│   ├── 🤝 Оркестрация
│   │   Стратег выбирает агентов → fanout → синтез → модалка
│   │
│   ├── 📋 Тендеры
│   │   Сейчас: парсеры (нестабильно)
│   │   После 1й продажи: платный API (Контур)
│   │
│   └── 📊 Аналитика
│       Фаза 2: базовая + голосовые запросы
│       Фаза 3: когорты, прогноз, эффективность агентов
│
├── 💯 ФИЧА: Балльная воронка лидов
│   ├── Балл (0-100) задаёт менеджер вручную
│   ├── Система даёт только ПОДСКАЗКУ (suggestedScore)
│   ├── Агенты НЕ перезаписывают score (дефолт)
│   └── P1✅ → P2✅ → P3 (SLA, экспорт)
│
├── 🥞 СТЕК
│   Frontend:  SvelteKit + Tailwind
│   Backend:   FastAPI + PostgreSQL + Redis
│   Агенты:    LangGraph (Стратег supervisor)
│   LLM:       Groq → Ollama fallback
│   Голос:     Groq Whisper → Hermes → voice_action
│   RAG:       Chroma (1592+ чанков)
│   Инфра:     Docker + Nginx
│
└── 📎 ПРИЛОЖЕНИЯ (A–G)
    A — Глоссарий терминов
    B — Чеклист приёмки P1
    C — Решения: шкала 0-100, балл = менеджер, суммы ₽
    D — Связь фич с фазами
    E — Нефункциональные (< 50ms, логи, русский UI)
    F — PII и данные
    G — Готовность к разработке (gate)
```

  данные      финансы    письма     продукт

  отчёты      прогноз    касания    RAG вендора

## Цикл голосовой команды

```
[Ты говоришь]
     ↓
  Whisper (STT)
     ↓
  Hermes: модуль + интент (JSON)
     ↓
  LangGraph → нужный агент(ы)
     ↓
  Действие в БД / Поиск / Email
     ↓
  UI-реакция: модалка | навигация | фильтр
     ↓
  [Апрув если надо → "да, отправляй"]
```
