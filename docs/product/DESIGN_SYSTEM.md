# SmartCRM — дизайн-система (текущее состояние)

> Снимок фактического UI на 2026-07-21 — точка отсчёта. При редизайне файл переписывается первым, потом код.
> Стек: SvelteKit + Tailwind CSS v4 (`@import "tailwindcss"` в `app.css`, без кастомного конфига — только стандартные токены Tailwind).

## Тема

Единственная тема — **тёмная**. Светлой темы нет.

## Цвета (фактические Tailwind-классы)

| Роль | Токен | Где |
|------|-------|-----|
| Фон приложения | `gray-950` | body, страницы |
| Фон панелей/карточек | `gray-900` | сайдбар, карточки, модалки |
| Фон элементов/hover | `gray-800` | строки, инпуты, hover |
| Границы | `gray-700` / `gray-800` | разделители, обводки |
| **Акцент (основной)** | `indigo-600` (hover `indigo-500`) | активный пункт меню, primary-кнопки, логотип |
| Акцент-текст | `indigo-300/400` | ссылки, выделения |
| Успех | `green-400` / `emerald-700/950` | статусы «онлайн», позитивные бейджи |
| Ошибка/опасность | `red-900/950` | ошибки, деструктивные действия |
| Предупреждение | `amber-950` / `yellow-900` | варнинги, ⚠️-бейджи |
| Текст основной | `white` / `gray-200/300` | заголовки, контент |
| Текст вторичный | `gray-400/500` | подписи, метаданные |
| Текст приглушённый | `gray-600` | disabled, плейсхолдеры |

## Типографика

- Шрифт: системный стек Tailwind (кастомный не подключён).
- Размеры: контент `text-sm`, подписи и мета `text-xs`, заголовки страниц `text-lg/xl`.
- Секции-заголовки в панелях: `text-xs font-medium uppercase tracking-wider text-gray-500`.

## Компоненты (паттерны)

| Паттерн | Классы |
|---------|--------|
| Primary-кнопка | `bg-indigo-600 hover:bg-indigo-500 text-white rounded-lg px-3 py-2 text-sm` |
| Secondary/ghost | `text-gray-400 hover:text-white hover:bg-gray-800 rounded-md` |
| Карточка/панель | `bg-gray-900 border border-gray-800 rounded-lg` |
| Инпут | `bg-gray-800 border-gray-700 rounded-md text-sm` |
| Бейдж статуса | цветной `*-900/950` фон + светлый текст того же оттенка |
| Активный пункт меню | `bg-indigo-600 text-white font-medium rounded-lg` |
| Индикатор-точка | `w-1.5 h-1.5 rounded-full` (`bg-green-400` вкл / `bg-gray-600` выкл) |

## Скругления и отступы

- Скругления: `rounded-lg` (панели, кнопки), `rounded-md` (мелкие элементы), `rounded-full` (точки, аватары).
- Отступы: базовая сетка Tailwind, типовые `px-2.5 py-2`, `gap-2.5`.

## Раскладка

- Левый сайдбар: сворачиваемый (`w-14` collapsed), скрывается на карточке лида; логотип-квадрат `indigo-600` c «S».
- Контент — остальная ширина; тяжёлые детали открываются slide-over (~65% ширины) поверх списка.
- Модалки — оверлей поверх текущего экрана (контекст не теряется) — канон `voice_action`.

## Тон и язык

- Весь UI — **русский**; технические термины (email, RAG, Ops) допустимы латиницей.
- Иконки навигации — юникод-символы (⬡ ⬢ ✉️ ◆), без icon-библиотеки.

## Известные долги (кандидаты редизайна)

- Нет собственных токенов (всё на дефолтной палитре Tailwind) — при редизайне завести `@theme` в `app.css`.
- Смесь `green`/`emerald` и `yellow`/`amber` — привести к одному оттенку на роль.
- Юникод-иконки — заменить на единый icon-set.
