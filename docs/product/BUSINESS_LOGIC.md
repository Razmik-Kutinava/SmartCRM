# SmartCRM — бизнес-процессы (сквозная картина)

> Как живёт сделка от поиска до закрытия и где включаются агенты. Детали модулей — `docs/modules/`; функции — [`FUNCTIONAL.md`](FUNCTIONAL.md).

## Главный цикл: лид от поиска до сделки

```
Лидоген (/leadgen)          Импорт (Битрикс / CSV)         Вручную / голосом
   ИНН, портрет, кластер          синк полей, истории            «добавь лид…»
        │                              │                              │
        └──────────────┬───────────────┴──────────────────────────────┘
                       ▼
              Новый лид в CRM (/leads)
                       │  скор ≥ 30 — автосейв из лидогена
                       ▼
              Обогащение (enrich): сайт, контакты, Checko, поиск
                       ▼
              Квалификация: балл (scoreAdvisory — совет, решает менеджер),
              приоритет, «Мой день» (dayRank)
                       ▼
              Работа по стадиям воронки (Kanban, гейты переходов)
              задачи · комментарии · касания · SLA · аудит полей
                       │
        ┌──────────────┼──────────────────┐
        ▼              ▼                  ▼
   Email-агент     Агенты (анализ,   Тендеры (если гос-закупки):
   переписка,      письма, прогноз)  мониторинг → разбор ТЗ →
   nurture-цепочки                   вердикт «участвовать / нет»
        └──────────────┴──────────────────┘
                       ▼
              Закрытие: won / lost → аналитика (воронка, когорты, прогноз)
```

## Роли в процессе

| Участник | Что делает | Чего не делает |
|----------|------------|----------------|
| **Оператор** | Ведёт воронку, даёт голосовые команды, апрувит письма/действия, ставит балл | Не пишет рутину руками |
| **Аналитик** | Данные лидов, отчёты, похожие лиды, метрики | Не меняет данные без команды |
| **Стратег** | Координирует агентов (fanout), синтезирует ответ, советует | Не действует без запроса |
| **Экономист** | Финансы, НМЦ/маржа, прогноз закрытия | — |
| **Маркетолог** | Письма, рассылки, цепочки до 20 касаний | Не отправляет без апрува |
| **Тех. спец** | Продукт, разбор ТЗ тендеров, RAG вендоров | — |

## Ключевые правила (инварианты)

1. **Балл лида ставит менеджер** — агенты дают только `scoreAdvisory` (совет + breakdown).
2. **Исходящее и деструктивное — только после апрува** (письмо, рассылка, удаление).
3. **Голос может всё, что может кнопка** — каждый модуль доступен через интент Hermes.
4. **Всё логируется**: касания, аудит полей, трейсы агентов — история восстановима.
5. **Знания накапливаются**: поиск, документы и диалоги пополняют RAG соответствующего агента.

## Побочные контуры

- **Email:** входящее → анализ типа (вопрос/апрув/жалоба/спам) → черновик агента → апрув → отправка; автолинк письма к лиду по домену.
- **Тендеры:** мониторинг ОКПД2/ключевых слов → карточка тендера → тех. спец + экономист → вердикт → задача/лид в CRM.
- **Self-improvement:** трейсы Hermes → eval → A/B промптов → суфлёр Стратега → новые версии промптов в Ops.
