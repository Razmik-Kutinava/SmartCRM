# SmartCRM — главные функции

> Что система обязана уметь — без этого продукта нет. Сквозные процессы — [`BUSINESS_LOGIC.md`](BUSINESS_LOGIC.md); статусы реализации — чеклисты фаз (`../operations/phase{N}/CHECKLIST.md`).

## 1. Лиды (CRM-ядро)

- CRUD лида, поля уровня Битрикс, мультиконтакты, суммы ₽/$
- Воронка Kanban с гейтами переходов стадий
- Задачи, комментарии, касания, аудит полей, SLA
- Список: фильтры, сортировка, группировка, CSV; быстро на 3000+ лидах
- Балл: `scoreAdvisory` (совет) + балл менеджера + приоритет + «Мой день»

## 2. Голос

- Микрофон → Whisper (STT) → Hermes (модуль + интент + слоты) → действие
- UI-реакции: модалка, навигация, фильтр, запрос апрува
- Работает по всем модулям: лиды, email, поиск, аналитика, агенты, база знаний

## 3. AI-агенты

- 5 агентов (Аналитик, Стратег, Экономист, Маркетолог, Тех. спец) — чат и команды
- Стратег-supervisor: fanout на нескольких агентов → синтез в один ответ
- У каждого агента свой RAG; промпты редактируются и версионируются в Ops

## 4. Email

- Подключение ящиков IMAP/SMTP; входящие в `/email` с фоновым синком
- Анализ письма → черновик ответа → апрув → отправка (голосом или кнопкой)
- Рассылки по сегменту, nurture-цепочки до 20 касаний, автоответ FAQ
- Автолинк переписки к карточке лида

## 5. Поиск и знания (RAG)

- Веб-поиск (Brave/Tavily/Serper) из UI и голосом
- Обогащение лида: сайт, контакты, реквизиты — в карточку
- Пополнение RAG: результаты поиска, PDF/DOCX, диалоги, краулинг вендоров

## 6. Лидогенерация

- Поиск новых лидов: ИНН-анализ, портрет, кластеризация
- Автосейв в CRM при скоре ≥ 30; lookalike по выигранным сделкам — с апрувом

## 7. Тендеры

- Поиск и мониторинг (ЕИС, TenderGuru, Serper) по ОКПД2/ключевым словам
- Разбор ТЗ тех. спецом + оценка экономистом → вердикт «участвовать / нет»
- Календарь дедлайнов, уведомления

## 8. Аналитика

- Воронка, конверсия, отчёты; голосовые запросы к метрикам
- v2: когорты, прогноз закрытия, эффективность агентов, срез по источникам

## 9. Ops (панель управления системой)

- Промпты агентов (редактирование, версии, A/B), трейсы, eval
- Конфиг CRM (стадии, веса скоринга), интеграции, лимиты

## 10. Интеграции

- Битрикс24 (импорт/синк полей, истории, продуктов), AmoCRM, HubSpot — по фазам
- CSV импорт/экспорт; Telegram-уведомления (Ф4+)
